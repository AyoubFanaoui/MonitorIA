
# MentorAI - Your Personalized Learning Coach (Promptless)

> Prototype developed for the **CODE IT v8.0** Hackathon  
> **Theme**: Coding Life & Reshaping Learning – *A Digital Renaissance Beyond Prompts*

---

## Overview

**MentorAI** is a smart web application that guides learners (programming, languages, data science...) without the need to formulate questions.  
The AI offers daily personalized challenges, manages smart reminders, and tracks user progress in a simple and motivating way, even offline.

---

## Problem We Solve
- Traditional AI tools require "prompts," which is a barrier for many beginners.
- Difficulty staying consistent and organized in self-learning.

---

## Proposed Solution
- 🎯 Automatically generated daily challenges.
- ⏰ Smart reminders based on the forgetting curve.
- 📊 Visual progress tracking.
- 🌐 Works even without an internet connection (offline mode).

---

## Target Audience
Moroccan students in self-training (development, data, languages...).
